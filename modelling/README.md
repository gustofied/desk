# Modelling

Research notebooks, methods and results.

- [GPU rental prices](rtx3090/): daily prices, historical baselines and seller repricing. [Article](https://www.adamsioud.com/exemplars/gpu-prices/).
- [Energy monitoring in buildings](building-energy/): an anonymised client project, illustrated with simulated readings. [Article](https://www.adamsioud.com/exemplars/building-energy/).
- [Vast.ai market data](vast-market/): listing turnover, availability and market segments.
- [Marconi100](marconi100/): power and temperature measurements from a supercomputer.

Each study includes instructions to reproduce its results. The [backend](../backend/)
contains the API skeleton; the research models run independently.
